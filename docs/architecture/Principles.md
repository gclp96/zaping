# Architecture Principles

1. Business before technology.
2. Modules communicate through public contracts.
3. Domain rules never depend on frameworks.
4. APIs are stable contracts.
5. Every business entity belongs to one Company.
6. Inventory is event-driven.
7. Documentation precedes significant implementation.
8. Security is built into every layer.
9. Favor simplicity over premature optimization.
10. Architecture evolves through documented decisions.
